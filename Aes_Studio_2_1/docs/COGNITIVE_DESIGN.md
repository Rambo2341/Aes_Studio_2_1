# Aes Cognitive Design

Aes does not claim biological consciousness or human-equivalent cognition. The system instead implements useful engineering analogues:

- **Working memory:** recent conversation turns and the current tool loop.
- **Long-term semantic memory:** owner-managed memories and retrieved knowledge.
- **Episodic memory:** saved conversations, feedback and audit traces.
- **Goal/task state:** projects plus the task ledger.
- **Attention:** retrieval selects memories/knowledge relevant to the current request.
- **Planning:** Plan sub-agent and Code+Review workflow.
- **Action:** permissioned tool registry.
- **Reflection/critique:** Review sub-agent and eval suite.
- **Learning:** approved examples -> dataset -> candidate -> eval -> owner publication.
- **Self-model/config:** versioned Aes model profile, identity prompt, skills and permissions.

This design lets Aes become more useful over time without pretending that reading psychology/neuroscience books automatically produces a human mind. Those books can be imported as knowledge or used in a lawful training corpus, while architecture changes remain explicit and measurable.
