# خطة تدريب Aes — Aes Training Plan

> **مجاني وخاص فيك:** العقل الافتراضي `Aes Local` يشتغل على كرتك (Ollama)، بدون أي مفتاح API وبدون فلوس.
> افتح **مركز التدريب** في الواجهة، واختر عدد الساعات (الافتراضي 3)، واضغط **ابدأ التدريب الآن**.
> أو ثبّت الجدول: `install_daily_task.bat 02:00`، ويتدرب كل ليلة 3 ساعات لحاله.

Aes يتعلم بطريقتين مختلفتين، ولازم تفرّق بينهم:

| الطريقة | وش تسوي | متى تتغير |
|---|---|---|
| **المعرفة والذاكرة** (Knowledge / Memory) | يقرأ صفحات ومجلات وكتب ومقاطع، ويحفظ ملاحظات مع مصادرها ويرجع لها بـ `recall` | فوراً، كل ليلة |
| **تدريب العقل** (LoRA fine-tuning) | يغيّر طريقة تفكير الموديل نفسه: أسلوبه، وكوده، واستخدامه للأدوات | كل ما يتجمع عندك بيانات كافية (أسابيع) |

ابدأ بالأولى على طول. الثانية تجي بعدين.

## Research Mode: برومت واحد وهو يتعلم مجال كامل

```
python main.py --research "Master Blender: modelling, UV, materials, rigging, animation, game export" --hours 8 --show-browser
python main.py --research "Unreal Engine 5 and Godot game development" --hours 6
python main.py --research "How the human brain learns: neuroscience of memory and attention" --hours 4
```

أو من صفحة **Autopilot**: اختر نوع الهدف **research**، واكتب البرومت، واكتب في التفاصيل عدد الساعات (مثلاً `hours: 8`).

وش يسوي:
1. **يخطط:** يقسم المجال إلى دروس مرتبة من الأساسيات إلى المتقدم.
2. **يقرأ:** يبحث في النت ويقرأ المقالات والـ PDF لكل درس.
3. **يشوف توتوريال:** يدور مقطع يوتيوب للدرس ويتعلم من الترجمة حقته.
4. **يخزّن:**
   - ملاحظات مع ذكر المصادر في المكتبة.
   - النص الأصلي كامل في مجلد `library\raw`، وهذا اللي يكبر مع الوقت.
5. **يكتشف مواضيع جديدة:** بعد كل درس يلقى 3 مواضيع جديدة لحاله ويكمل، لين يخلص الوقت.
6. مع `--show-browser` يفتح كل صفحة في Chrome عشان تشوفه وهو يقرأ.

## مكتبة ضخمة (تيرابايتات)

- **التخزين:** خلّ مجلد البيانات على هارد كبير عن طريق `aes_data_location.txt`.
- **الأسرع من التصفح:** نزّل بيانات جاهزة ومفتوحة، وبعدين استوردها بالأمر `python main.py --library "E:\Datasets\..."`. أمثلة:
  - تفريغ ويكيبيديا (عربي وإنجليزي) من dumps.wikimedia.org
  - كتب OpenStax المجانية (رياضيات، فيزياء، كيمياء، أحياء)
  - Project Gutenberg
  - أوراق arXiv
  - توثيقات Blender وUnity وGodot وUnreal وRoblox
- **حقيقة مهمة:** تصفح النت بطيء، مئات الصفحات في الساعة. يعني 10 TB من التصفح بس ياخذ سنين. البيانات الجاهزة أسرع بكثير.
- **المعرفة غير الذكاء:** 10 TB تخلي Aes **يلقى** المعلومة بسرعة، بس ما تخليه **يفكر أذكى**. الذكاء يجي من العقل، يعني الموديل والتدريب.

## مفتاح API (Claude / OpenAI / DeepSeek / Gemini)

مفتاح API يعطي Aes أقوى عقل على طول، بدون تدريب:
- **Claude:** في cmd اكتب `setx ANTHROPIC_API_KEY "مفتاحك"` وسكّر Aes وافتحه من جديد. بعدها في Models اختر `Aes 2.2 Claude` واضغط Test.
- **DeepSeek:** `setx DEEPSEEK_API_KEY "..."` واختر `Aes 2.2 DeepSeek`.
- **مزوّد ثاني متوافق مع OpenAI:** سوّ بروفايل من نوع `openai_compat`، وحط فيه عنوان المزوّد، وفي خانة المفتاح اكتب `env:اسم_المتغير`.
- لا تحط المفتاح داخل ملفات المشروع، ولا ترسله لأحد.
- الاستخدام بالمفتاح مدفوع حسب الكمية. راقب الفاتورة من لوحة المزوّد.
- شروط Anthropic ما تسمح تستخدم ردود Claude لتدريب موديل منافس. عشان كذا Aes 3.0 يتدرب من بياناتك وتمارينه اللي يتحقق منها الكمبيوتر.

## الاستضافة

- استضافة Hostinger العادية وخوادم الـ VPS حقتها **ما فيها GPU**، يعني **ما تقدر تدرّب عليها موديل**.
- ممكن تستخدمها لموقع Aes أو لسيرفر API بسيط.
- التدريب يحتاج GPU مستأجر بالساعة من RunPod أو Vast.ai أو Lambda. شوف القسم اللي تحت.

## التدريب اليومي التلقائي (الأهم)

أمر واحد كل ليلة يسوي كل شي:

```
install_daily_task.bat          ← يسجّله في ويندوز يشتغل كل ليلة الساعة 2 (تقدر تغيّر الوقت: install_daily_task.bat 03:30)
run_daily_training.bat          ← تشغيل يدوي
python main.py --daily          ← نفس الشي من الطرفية
```

كل ليلة يمر بست خطوات:
1. **المدرسة:** ياخذ الوحدات الجاية من المنهج (3 كل ليلة) ويدرسها ويتمرن عليها. يمشي بالتوازي في كل المواد عشان ما يقوى في مجال وينسى الباقي.
2. **التمارين:** مسائل رياضيات وفيزياء وكيمياء جديدة كل يوم، الكمبيوتر يصححها بالحساب الدقيق. ومسائل برمجة يصححها باختبارات مخفية.
3. **الحصاد:**
   - الأجوبة الصحيحة المتحقق منها تصير أمثلة تدريب.
   - الأجوبة الغلط تصير أمثلة تصحيح فيها الجواب الصح.
   - ينضاف لها كل شغل خلّصه Autopilot، وكل رد عطيته 👍.
4. **الامتحان:** يختبر نفسه ويسجّل الدرجة.
5. **نمو العقل:** إذا تجمع 300 مثال جديد ممتاز، يدرّب نسخة جديدة من العقل (LoRA) تلقائياً. هذي الخطوة مقفلة لين تفعّلها بنفسك من الإعدادات: `daily_lora_enabled=1`، و`daily_lora_base` تحط فيه اسم الموديل الأساسي.
6. **التقرير:** ملف `reports\daily_*.md` فيه درجات اليوم وجدول تقدّمه لآخر 14 يوم.

ليش التمارين مصححة بالكمبيوتر؟ عشان Aes ما يتعلم من أخطائه. ما يدخل التدريب إلا الشي اللي انثبت إنه صح.

## إعدادك: RTX 3070 (8 GB) + سيرفر GPU مستأجر

| الشغلة | وين | التفاصيل |
|---|---|---|
| **تشغيل العقل يومياً** | جهازك (3070) | بروفايل `Aes 2.2 RTX 3070`، وتنزّله بالأمر `ollama pull qwen2.5vl:7b`. يشوف الشاشة، وحجمه حوالي 6 GB فيدخل في كرتك. |
| **عقل كود أقوى (بدون رؤية)** | جهازك | `ollama pull qwen2.5-coder:7b`. للمهام اللي ما تحتاج يشوف فيها الشاشة. |
| **تدريب صغير (تجربة)** | جهازك | QLoRA على `Qwen/Qwen2.5-Coder-1.5B-Instruct` أو 3B. بطيء بس يمشي. |
| **تدريب Aes 3.0 الحقيقي (7B)** | سيرفر مستأجر | GPU فيه 24 GB أو أكثر (RTX 4090 أو A100) بالساعة. التدريب عادة ياخذ 1 إلى 3 ساعات لكل 1000 إلى 3000 مثال. |
| **تشغيل Aes 3.0 بعد التدريب** | جهازك | ملف GGUF بصيغة Q4_K_M، حجمه حوالي 4.7 GB، ويدخل في الـ 3070. |

**السيرفر المستأجر:** لا تشتري استضافة شهرية للتدريب. استأجر GPU **بالساعة** وقت التدريب بس، مثلاً مرة بالشهر من RunPod أو Vast.ai أو Lambda. وAes نفسه يظل شغال على جهازك لأنه يتحكم بالماوس والشاشة حقتك.

**خطوات التدريب على السيرفر:**
1. من Training Lab سوّ **Export JSONL**.
2. ارفع مجلد المشروع والملف على السيرفر.
3. شغّل:
   ```
   AES_TRAIN_ARGS=--qlora bash trainer/cloud_train.sh aes_training_XXXX.jsonl Qwen/Qwen2.5-Coder-7B-Instruct aes-3.0
   ```
4. نزّل الملف `out/aes-3.0-Q4_K_M.gguf` على جهازك.
5. في Aes افتح **Models**، اختر `llama_cpp`، وحدد ملف الـ GGUF. بعدها شغّل **Evals** وقارن درجته بالعقل القديم.

**الرخصة:** `Qwen2.5-Coder-7B` و`Qwen2.5-VL-7B` رخصتهم Apache 2.0، يعني تقدر تستخدمهم وتبيعهم. نسخة **3B** رخصتها مختلفة (للبحث بس)، فلا تعتمد عليها إذا تبي تبيع Aes. وتأكد دايماً من ملف الرخصة في صفحة الموديل.

## المرحلة 0: التجهيز (يوم واحد)

1. `run_windows.bat`، وبعدين من **Models** اختر العقل واضغط **Test model** ثم **Set default**.
   - عشان يشوف الشاشة لازم عقل يدعم الصور (vision): Claude، أو Ollama مع موديل vision مثل `qwen2.5vl`.

   ```

   ```
3. هارد خاص للذاكرة: غيّر اسم `aes_data_location.example.txt` إلى `aes_data_location.txt` واكتب فيه مثلاً `D:\AesBrain`.
4. من الشات اختر وضع الثقة **Auto** (يمشي حسب سياسة كل أداة) أو **Full access** (بدون أي سؤال).

## المرحلة 1: المدرسة (كل ليلة)

المنهج موجود في `curriculum/aes_curriculum.json`، وفيه 41 وحدة بالترتيب: **ابتدائي ← متوسط ← ثانوي ← جامعة ← تخصص**. المسارات:

`computer` استخدام الجهاز وكروم · `programming` (JS/TS، Lua/Luau، C#، C++، Git، خوارزميات) · `roblox` · `3d` (Blender) · `unity` · `math` · `physics` · `chemistry` · `ai`

كل وحدة تتحول إلى هدفين:
1. **Study:** يبحث في النت، ويقرأ المصادر الرسمية، ويكتب ملاحظات مع ذكر المصادر.
2. **Practice:** تمرين حقيقي له "تعريف إنجاز" (Definition of Done). يكتب الكود ويشغّله، أو يتحكم بالشاشة ويتأكد، أو يتحقق من الرياضيات بـ Python.

تشغيله:
- **من الواجهة:** صفحة **Autopilot**، ثم **Load training plan**، ثم **Run Autopilot now**.
- **من الطرفية:**
  ```
  python main.py --curriculum computer,programming --max-level middle
  run_autopilot.bat
  ```
  الأفضل تبدأ بـ `computer` عشان يتعلم يستخدم جهازك قبل أي شي ثاني. بعدها زِد المستوى شوي شوي.

التقرير يطلع الصبح في `<data>\reports\autopilot_*.md`.

## المرحلة 4: تدريب Aes 3.0 (LoRA)

اختر الموديل الأساسي حسب ذاكرة كرت الشاشة عندك (VRAM). السكربت الحالي يدرّب بدقة كاملة، فهذي الأرقام تقريبية:

| VRAM | موديل أساسي مقترح |
|---|---|
| 8 GB | `Qwen/Qwen2.5-Coder-1.5B-Instruct` |
| 12–16 GB | `Qwen/Qwen2.5-Coder-3B-Instruct` |
| 24 GB أو أكثر | `Qwen/Qwen2.5-Coder-7B-Instruct` |
| أقل من كذا | استأجر GPU سحابي لساعات قليلة (A100/H100) |

```
pip install -r trainer/requirements-training.txt
python trainer/train_lora.py --base Qwen/Qwen2.5-Coder-3B-Instruct --dataset exports\aes_training_XXXX.jsonl --output models\aes3-lora --epochs 2
python trainer/merge_lora.py --base Qwen/Qwen2.5-Coder-3B-Instruct --adapter models\aes3-lora --output models\aes3-merged
```

بعدها حوّله إلى GGUF بأدوات llama.cpp (`convert_hf_to_gguf.py` ثم `llama-quantize` بصيغة Q4_K_M). بعدها في **Models** سوّ بروفايل `Aes 3.0` من نوع `llama_cpp` واختر ملف الـ GGUF.
