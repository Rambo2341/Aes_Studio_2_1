# Aes local models

Aes Studio does not bundle third-party model weights. Import a legally usable GGUF model in the **Models** page.

Suggested versioning convention:

- `Aes-1.0-8B.gguf`
- `Aes-1.1-8B.gguf`
- `Aes-2.0-14B.gguf`
- `Aes-2.1-32B.gguf`

If Aes is fine-tuned from another open-weight model, keep the original license and attribution requirements with your release.
